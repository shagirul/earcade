# Pitch Arcade

Run the React app locally.

```bash
npm i
npm run dev
```

Note Rush is a landscape-only pitch exercise. The training home includes a piano warm-up link, the personal best, and previews for upcoming exercises.

Synth Lab is a playable synthesizer with presets, a waveform editor, effects, and a two-octave keyboard. Open it from its home card or at `/synth-lab/`.

The [design system](UI_KIT.md) documents the shared UI tokens and audio plugin entry point.
